# SPECIFICATION DU LOGICIEL

## Nom du projet

Logiciel de Gestion ETS AZINNON ET FILS

---

# Présentation

Le logiciel est destiné à gérer toutes les activités de ETS AZINNON ET FILS.

Le système doit être simple, rapide, sécurisé et professionnel.

---

# Activités de l'entreprise

- Vente de motos
- Vente de motos à crédit
- Gestion des paiements
- Gestion du stock
- Location de bus
- Gestion des clients
- Comptabilité
- Rapports
- Tableau de bord

---

# Objectifs

Le logiciel doit permettre :

- Gérer les motos
- Suivre les stocks
- Enregistrer les ventes
- Gérer les ventes à crédit
- Suivre les paiements
- Calculer les soldes
- Gérer les locations de bus
- Générer des factures
- Générer des contrats
- Générer des reçus
- Produire des statistiques

---

# Utilisateurs

Le logiciel possède plusieurs profils.

- Administrateur
- Gestionnaire
- Caissier
- Comptable
